# claude-todo-demo

A clean, modern to-do list app in a single `index.html` file — HTML, CSS and JavaScript all inline, with no build step and no dependencies.

## Features

- Add, complete, edit (double-click or the pencil icon) and delete tasks
- Filter by All / Active / Completed, and clear completed tasks
- Progress bar and remaining-task count
- Light and dark mode (follows your system setting, toggle in the top right)
- Tasks are saved in the browser's `localStorage`, so they survive a refresh
- Keyboard friendly, responsive, and respects reduced-motion settings

## Run / deploy

Open `index.html` in a browser, or drop it on any static host (GitHub Pages, Netlify, Vercel, S3…).

For GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
